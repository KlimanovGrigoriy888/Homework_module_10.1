# Проект Homework_10.1

## Описание:

Проект Homework_10.1 - это приложение на Python  которое  обрабатывает информацию банковских реквизитов. В настоящее время в разработке. 

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/KlimanovGrigoriy888/Homework_module_10.1.git
```
## Использование:

1. Клонируйте код в PyCharm.
2. В настоящее время реализованны функции обработки номера карты или счета в выводом готовой маски этих номеров, типа: Visa Platinum 7000 XX** **** XXXX, Счет **XXXX..
3. Далее добавлена функция обработки даты стандартного ввода в виде строки и в формате похожем на datetime и преобразуется в нужный формат "ДД.ММ.ГГГГ"
4. Так же в разработке функция которая принимает список словарей и опционально значение для ключа state (по умолчанию'EXECUTED'). Функция возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению.
