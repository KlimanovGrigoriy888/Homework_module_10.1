# Проект Homework_10.1

## Описание:

Проект Homework_10.1 - это приложение на Python которое обрабатывает информацию банковских реквизитов с целью преобразования в готовый вид-маску, для отфильтровывания списков словарей с id по ключам 'state' и 'data'. В настоящее время проект в разработке и не имеет оконченный вид т.е. реализованную конечную функцию. 

## Установка:

1. Клонируйте репозиторий из PyCharm:
```
git clone https://github.com/KlimanovGrigoriy888/Homework_module_10.1.git
```
2. Проверьте имеется ли у вас менеджер зависимостей poetry выполнив команду:
```
poetry --version
```
3. Если в PyCharm нет poetry установите Poetry через команду:
```
pip install poetry
```
4. Для установки зависимостей проекта из файла pyproject.toml исполните команду:
```
poetry install
```

## Использование:

1. Клонируйте код в PyCharm, так как проект не имеет конечной функции, то здесь опишу реализованные функции в модулях.
2. В модуле masks.py реализованны функции обработки номера карты или счета c выводом готовой маски этих номеров, типа: Visa Platinum 7000 XX** **** XXXX, Счет **XXXX..
3. В модуле widget.py реализованна функция которая отфильтровывает номер счета от номера карты и использует функцию из модуля masks.py для обработки номера карты или счета со стандартного ввода в виде строки. Так же написана функция которая принемает строку в формате "2024-03-11T02:26:18.671407" и возвращает "ДД.ММ.ГГГГ"
4. Добавлен модуль Processing.py который принимает список словарей и опционально значение для функций filter_by_state ключ сортировки 'state' (по умолчанию'EXECUTED') и для функции sort_by_date ключ key_sort. Функция filter_by_state возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению, а функция sort_by_date сортирует список по дате, с учетом значения ключа key_sort по возрастанию или убыванию
